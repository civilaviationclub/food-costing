# Food Costing

Food costing application hosted by Civil Aviation Club. Original application branding and creator credit retained.

Recipe costing, ingredient yield calculations, selling prices, saved recipe records, summary, backup/restore and offline installation. Records remain in each browser on each device. No cloud synchronization, server uploads or analytics. Public repository contains app code and generic icons only. Keep exported backups private.

To move existing recipes: export a backup from the original app and restore it here.
